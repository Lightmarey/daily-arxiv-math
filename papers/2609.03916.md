**完成的工作**

证明全局各向异性 perimeter minimizer 的 halfspace theorem：先建立 wall maximum principle 和薄 slab 正则性，再用 logarithmic barriers 控制无穷远，最后将墙面缺陷分裂并以 trace incompatibility 排除非半空间极小集。

**使用技术**

- 各向异性 BV/perimeter
- 墙面最大值原理
- 薄 slab 正则性
- 对数势垒
- blow-down 紧性

**可能的突破**

在一般各向异性 integrand 下把全局 perimeter 最小性与半空间几何刚性连接起来，并同时处理边界墙面、无界缺陷和全局 blow-down。

**限制与不确定性**

要求各向异性 integrand 满足文中光滑性、凸性和椭圆性条件；半空间定理的维数和全局最小性范围受这些几何假设约束。

**证明逻辑/大纲**

1. **主张：** 全局最小集在墙面附近满足支撑与薄 slab 正则性。
   - **路线：** 用 anisotropic perimeter 的局部比较和 wall-trace maximum principle 排除穿越墙面的接触，再对薄 slab 做密度/单调性估计，得到单页图形收敛。
2. **主张：** 各向异性对数势垒限制了远离墙面的缺陷增长。
   - **路线：** 构造严格各向异性 logarithmic barrier，并按尺度缩放；比较原理将 minimizer 的边界压在渐近平面两侧，控制 blow-down 的偏离。
3. **主张：** 无界极小集可分解为墙面半空间与内部缺陷。
   - **路线：** 用 BV current 的 subadditivity、monotone truncation 和 codimension-one filling，将集合与墙面半空间的差写成 defect current，并保持绝对最小性。
4. **主张：** 墙面 trace incompatibility 排除非空缺陷，留下半空间。
   - **路线：** 对 defect 使用 simultaneous blow-down 和 wall-trace 约束；若缺陷非空，其 wall trace 与最小性产生互相矛盾，故 defect 为空并得到 Theorems 1\.1、1\.4。

**排序理由**

结合几何测度论极小化、障碍构造与 blow-down 刚性，主题与变分方法和几何型 PDE 的结构性复用高度相关。

**原始英文摘要**

We prove an arbitrary-dimensional halfspace theorem for global minimizers of a smooth uniformly elliptic anisotropic perimeter: if the nonempty boundary of a minimizing set is contained in a halfspace, then the set itself is a halfspace\. No evenness of the integrand or regularity of the minimizing boundary is assumed\. The proof combines wall contact with a plane-peeling argument for the complementary phase defect and a simultaneous second blow-down\. We also give a direct, self-contained exterior-barrier proof of the two-dimensional stationary anisotropic statement\. Its rigidity conclusion is already covered by Bergner's earlier halfspace theorem; the proof is retained because it works directly with the anisotropic Euler-Lagrange operator\.
