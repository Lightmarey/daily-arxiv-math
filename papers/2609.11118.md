**完成的工作**

论文研究常系数一维双曲平衡律在单侧边界控制下的最小零控制时间。对仅有一个负速的情形，作者用系数构造的非线性递归序列 $\psi ^r$ 和正交条件 $⟨b,\psi ^r⟩=0$ 定义嵌套集合 Ck，证明 Tinf 只能取 $\tau _{2},…,\tau n+1$ 且 $Tinf=\tau k$ 当且仅当 $(M,q)\in Ck\Ck+1$；随后给出 $n=3、4$ 时递归检查长度的上界，并在附录证明相关 kernel 方程的存在唯一性。

**使用技术**

- 特征线表示
- backstepping kernel 方程
- 非线性递归序列 $\psi ^r$
- 正交性与最小控制时间
- Banach 不动点/Volterra 积分方程

**可能的突破**

论文把内部耦合矩阵、边界耦合和传播速度压缩成可计算的递归正交条件，首次在一个负速的常系数系统中给出最小控制时间的离散分类，并量化 $n=3、4$ 时所需检查的条件数。

**限制与不确定性**

主要结果限于常系数、线性、单侧控制和特定速度符号分裂；一般 n 的 $N\psi $ 上界仍未知，附录 kernel 正则性也依赖延拓到特征线域的构造。

**证明逻辑/大纲**

1. **主张：** 单负速系统的最小控制时间只可能是 $\tau _{2},…,\tau n+1$，并由 Ck&#92;Ck&#43;1 精确分类。
   - **路线：** 沿特征线消去受控负速分量，把 kernel 方程的级数系数递推编码为 $\psi ^r$；每多一个时间层，必须增加 $q_{i-1}=0$ 和 $⟨b,\psi ^r⟩=0$ 的可消去条件，于是获得 $C2\supset …\supset Cn+1$ 的分层判别。
2. **主张：** 正交条件序列在三、四维分别至多需要 3、6 个独立检查。
   - **路线：** 利用 $\psi ^r$ 递归中的有限维线性包络和特定 n 的 Cayley–Hamilton 关系，证明后续序列落在前几项张成空间；因此无限 r 的正交性等价于前 $N\psi $ 项。
3. **主张：** backstepping kernel 方程在特征线域 D 上存在唯一 $C^s$ 解并有数据范数估计。
   - **路线：** 先沿第 i 条特征线显式解出 ki（70），代回其余分量得到积分映射 $\Phi =\Phi _{1}+\Phi _{2}$；特征线交点估计 &#40;69&#41;、&#40;72&#41; 给出 $\Phi ^N$ 的阶乘衰减 $C^N|x-\xi |^N/N$&#33;，故 Banach 不动点获得唯一连续解，再逐阶微分提升 $C^s$。
4. **主张：** Theorem 1.3 的零控制时间结论也适用于有限时间稳定化。
   - **路线：** backstepping 构造给出的 kernel 变换把原系统映到有限传播的目标系统；同一正交消去条件使边界输入在 $\tau k$ 前后逐层清空，因此把 null controllability 的判别传递给 $L^{2}$ 有界反馈稳定化。

**排序理由**

把最小控制时间转成递归正交条件和有限维代数分类，并补足三、四维 kernel 条件的可操作上界。

一般维度的递归长度仍无统一界，空间变系数和非线性双曲系统不在结论范围内。

**原始英文摘要**

In this work, we study the null controllability by one&#45;sided boundary controls of one&#45;dimensional hyperbolic balance laws with constant coefficients. Our first result shows that, when the system has only one negative or positive speed, the minimal null control time of such systems depends on some orthogonality conditions for a particular sequence. This sequence is explicit in function of the coefficients of the system but it is defined by a nonlinear recurrence relation. Our second result then completes the previous one by giving explicit bounds on the number of orthogonality conditions that have to be checked in two nontrivial situations. The proofs rely on a careful analysis of the so&#45;called kernel equations associated with the system, including a new well&#45;posedness result. Our results are also valid for the finite&#45;time stabilization property.
