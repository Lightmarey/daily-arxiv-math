**完成的工作**

论文提出 product of cyclic groups 上 polynomial Bohnenblust–Hille bound 的一条 self&#45;contained proof route。对 interaction order 分层后，作者把 Potts hypercontractivity、固定低阶 spectral projection 和 mixed&#45;norm interpolation 接入加权 graded square function。随机把 active coordinates 二染色，保留每个局部 Fourier degree 并以 exact ancestry 回收 parent coefficient；binomial central capture 与 Potts entropy contraction 控制高 interaction levels。低阶层先单独闭合，高阶部分通过 uniform contraction 和 bootstrap 得到 weighted square&#45;function $O(d^3)$，最后将权重还原为 coefficient $l^p$ 范数，得到固定 K 时 $C(K)d^(4$ $gamma_K+5)$ 的 proposed polynomial bound。

**使用技术**

- Potts hypercontractivity
- interaction&#45;order Fourier projections
- weighted row–column square&#45;function bootstrap
- random coordinate bicoloring and exact ancestry
- binary&#45;entropy contraction

**可能的突破**

将 support&#45;layer 的随机坐标二染色与 Potts hypercontractivity 结合，建立统一收缩常数小于 1 的加权 bootstrap，从而把 cyclic&#45;group Bohnenblust–Hille 的 degree dependence 从既有 subexponential 机制推进到固定 K 下的 polynomial exponent 4 $gamma_K+5$；作者同时明确指出该结果不 uniform in K。

**限制与不确定性**

论文标题和 Theorem 1.1 将结果称为 proposed proof，结论只对每个固定 K 成立，常数和指数均随 K 变差；证明依赖既有 Potts hypercontractivity、低 interaction&#45;level estimate 和 projection estimate，不能直接宣称 uniform&#45;K 或非交换群版本。AI 曾参与 Section 5 &#91;19&#93; 的探索性证明开发，但数学内容由作者核验并编辑。

**证明逻辑/大纲**

1. **主张：** Potts hypercontractivity、低 interaction levels 和 projection estimate 为各 support layer 提供初始 weighted bounds。
   - **路线：** 用 $T_rho$ 的谱作用把 interaction order r 的 Fourier layer 衰减为 $rho^r$；对 $r=1,2,3$ 直接调用 support&#45;sensitive bound，对一般 r 用负 Potts interval 保持 L&#45;infinity contraction，并以一维 Markov kernel 的正性控制 projection。
2. **主张：** 混合范数插值和 row–column square function 将二块 Fourier 系数控制为 weighted bootstrap 递推。
   - **路线：** 对随机二分后的两块 interaction degrees 使用 fractional two&#45;block interpolation，把行和列的系数范数分别放入混合 $l^p/l^2$ 范数；再用 variable&#45;angle summation 和 weighted square function 汇总所有 balanced bidegrees，产生带 entropy weight 的递推量 Gamma。
3. **主张：** 随机坐标二染色在高 interaction levels 上保持 parent coefficient 并产生统一概率捕获。
   - **路线：** 每个 active coordinate 整体分配到 x 或 y block，局部频率不被合并；因此子系数的支持并集唯一恢复 parent index。二染色计数服从 Bin&#40;r,1/2&#41;，中心区概率至少为 1/3，结合中央 entropy contraction 得到 Proposition 8.1 的高层递推。
4. **主张：** uniform contraction 使 weighted square function bootstrap 闭合，并推出 polynomial Bohnenblust–Hille bound。
   - **路线：** 取 $B_K=4$ $gamma_K+2$ 后，显式计算 contraction $c_star=0.820772...<1$；将低层常数与高层递推相加并移项，得到 $Gamma\le D_K$ $M^3$。最后按 $p_r\le p_d$ 的单调性把每层系数求和，恢复 $d^(4$ $gamma_K+5)$ 的 $l^p$ 估计。

**原始英文摘要**

Fix an integer $K\ge2$, and let $C_K^n =\{(e^{\frac{2πij}{K}})_{j=0}^{K-1}\}^n$ be the product of cyclic groups of order $K$. For a Fourier character $χ_α$, let $s(α)$ be the number of active coordinates. We give a self&#45;contained proposed proof that the dimension&#45;free Bohnenblust&#45;&#45;Hille constants governed by interaction order grow polynomially: if $p_d=2d/(d+1)$ and 

$$γ_2=\frac12, \qquad γ_K=\frac{K\log(K-1)}{4(K-2)}\quad(K\ge3),$$

 then the $\ell^{p_d}$ norm of Fourier coefficients $\{\hat f(α)\}$ is bounded by $L^\infty$ norm of $f$ multiplied by $C(K) d^{4γ_K+5}$. The constant $C(K)$ is actually at most of the order $K^{5/2}$.
