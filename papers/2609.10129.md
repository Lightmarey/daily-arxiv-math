**完成的工作**

论文研究从圆盘到球面的一协旋 harmonic map heat flow，在 Dirichlet 边界控制下如何阻止或促成 bubble blow&#45;up。作者设计与控制适配的 gluing：以小参数 $\lambda $ 构造正的上 profile $q^{\lambda ,0}$，加入变号环状模态和 well&#45;prepared boundary trace，使初值位于 profile 下方时恒定边界仍在有限时间爆破，而对应的受控边界将解压到 $\pi $ 以下并保持全局；有界时间导数进一步排除无限时集中。比较原理和终端 clearing 给出控制下的全局性，最后分别构造任意快的控制爆破和任意小幅有界控制也无法阻止的内核爆破。

**使用技术**

- control&#45;adapted gluing
- one&#45;corotational heat flow
- radial sub/supersolutions
- sign&#45;changing annular mode
- comparison and terminal clearing

**可能的突破**

建立了边界控制的双向机制：同一类略高于 $\pi $ 的初值可由精心准备的迹全局稳定，也可被光滑控制任意提前推入爆破；同时证明对某些接近 $\pi $ 的初值，所有幅度有界控制都无法避免有限时集中。

**限制与不确定性**

主要结果限于一协旋、非负或特定 profile 的圆盘到球面流，并依赖比较序结构；Theorem 1.4 的任意快爆破允许控制导数变大，Theorem 1.5 只对预先构造的非负内核 profile 说明有界控制无效，不能推广到任意变号数据。

**证明逻辑/大纲**

1. **主张：** 小 $\lambda $ 的静态 profile $q^{\lambda ,0}$ 为正且边界值超过 $\pi $，可作为控制适配的上障碍。
   - **路线：** 将椭圆 profile 方程写成径向一维问题，利用 $\lambda \to 0$ 的极限和正性估计控制其零点；边界迹参数由 profile 的终端值确定，得到 $q0\le q^{\lambda ,0}$ 的比较起点。
2. **主张：** 恒定边界会使低于上 profile 且边界值大于 $\pi $ 的解有限时爆破，而 well&#45;prepared 控制迹使解在有限时间进入 $q<\pi $ 区域。
   - **路线：** 把 sign&#45;changing annular mode 拼入 profile，在接口处设置严格正 margin；对恒定迹用 CDY bubble 的下解比较推进尺度塌缩，对控制迹则用上解和终端 clearing 把外侧边界影响传入内区，T1 时刻得到全域严格低于 $\pi $。
3. **主张：** 若控制迹的时间导数在 T1 后有界，则受控解全局并排除无限时集中。
   - **路线：** T1 后解落在 $\pi $ 以下的安全序中，抛物正则性给出局部 $H1/L\infty $ 控制；控制导数上界防止边界重新制造临界梯度，反复应用 continuation criterion 得到任意有限时间延拓，并从统一梯度估计排除尺度趋零。
4. **主张：** 非负初值可被光滑控制在任意指定时间前推入有限时爆破；另一方面存在略高于 $\pi $ 的 profile 对所有幅度有界控制都爆破。
   - **路线：** 任意快爆破先用足够大的正边界迹在短时间把解抬过小尺度 CDY 下 profile，再利用其 O&#40;sqrt&#40;lambda0&#41;&#41; 崩塌时间；有界控制情形把小尺度 profile 放在固定内区并保留接口 margin，短时间边界影响不足以消除 margin，故内核仍按下解塌缩。

**原始英文摘要**

We study the one&#45;corotational harmonic map heat flow from the disk to the sphere with a Dirichlet boundary control. We introduce a control&#45;adapted gluing strategy to prevent blow&#45;up. More precisely, we construct explicit upper profiles and well&#45;prepared boundary traces such that every nonnegative datum below one of these profiles and having boundary value above $π$ blows up under the corresponding constant trace, whereas the corresponding solution is global under every control below the associated well&#45;prepared boundary trace. Controls with uniformly bounded time derivative also prevent infinite&#45;time concentration. We also show that boundary control can drive any nonnegative datum to blow&#45;up before any prescribed time, whereas bounded controls cannot prevent suitably fast concentration.
