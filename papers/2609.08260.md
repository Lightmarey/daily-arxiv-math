**完成的工作**

本文将 Riemann 流形上的 quadrature surface 自由边界问题从 Laplace–Beltrami 算子推广到 p&#45;Laplacian。给定 $f\in L^p$、全凸包 C 和常数 k，作者在满足 RC&#45;GNP 与 boundary&#45;flux stability 的 admissible class 中以 p&#45;能量减去 $k^{p}$ 体积建立形状泛函。首先证明域紧性和 p&#45;Laplacian Dirichlet 解的 $W^{1,p}$ 稳定性，直接法得到最优域；接着通过 p&#45;能量形状导数和第一阶变分获得边界梯度条件。最后用 p&#45;Laplacian 比较原理、Hopf 引理和接触处几何比较，证明存在严格包含 C 的解当且仅当 ∫C $f,dv_g>k^{p-1}|\partial C|_g$。

**使用技术**

- RC&#45;GNP 域紧性与特征函数收敛
- p&#45;Laplacian 单调性和 $W^{1,p}$ 稳定性
- p&#45;能量直接法
- Hadamard 形状导数与变分不等式

**可能的突破**

论文得到 p&#45;Laplacian 版本的几何必要充分判据，把欧氏 $p=2$ 结果和 Riemann Laplace 结果统一为 ∫C $f,dv_g>k^{p-1}|\partial C|_g$；严格包含性由全凸包接触分析与 p&#45;通量的单调性共同保证。

**限制与不确定性**

结论要求紧致连通单连通、非负截面曲率的 Riemann 流形$，f\in L^p$ 非负且 C 严格凸，并假设 admissible class 满足 RC&#45;GNP 与 &#40;SC&#41; 边界通量稳定性。p&#45;Laplacian 的边界正则性和 Hopf 引理需文中光滑性/非退化梯度条件；未覆盖一般曲率、退化接触或不稳定 admissible 类，也未研究稳定性与数值近似。

**证明逻辑/大纲**

1. **主张：** admissible 域列及其 p&#45;Laplacian 解具有足够紧性，能把最小化序列取到极限。
   - **路线：** RC&#45;GNP 给出 defining functions 的统一 $C^{2,\alpha }$ 控制，Theorem 2.2 提取 Hausdorff 和 $L^{1}$ 特征函数收敛；对每个域的 p&#45;Dirichlet 解，能量界、弱紧性与 p&#45;Laplacian 严格单调性识别极限，Theorem 2.3 得到 $W^{1,p}$ 强稳定性。
2. **主张：** 形状泛函存在最小域，并满足自由边界上的一阶梯度条件。
   - **路线：** 用上一阶段的域/解收敛和 p&#45;能量下半连续性对最小化序列取极限，Theorem 3.1 得到 $\Omega *$。随后 Theorem 4.1 对域变形求 p&#45;能量形状导数，任意法向变分给出 $\Omega *\\partial C$ 上 $|\nabla u|=k$，接触 C 的部分给出 $|\nabla u|\le k$。
3. **主张：** 与全凸包接触时，比较原理和 Hopf 引理把最优性转成边界通量的严格不等式。
   - **路线：** 在接触点比较 C 上的解 uC 与最优域解 $u\Omega *；Lemma$ 2.4 给出函数序关系，Lemma 2.5 在相同法向和非零梯度下给出严格法向梯度比较。结合 C 与 $\Omega *$ 边界的二阶形状比较，得到若 $\Omega *$不严格包含 C，则 $|\nabla uC|^{p-1}<k^{p-1}$，可积分为与源质量条件矛盾的边界通量界。
4. **主张：** ∫C $f,dv_g>k^{p-1}|\partial C|_g$ 是严格包含 C 的 quadrature surface 存在性的充要条件。
   - **路线：** 必要性对假设解使用 p&#45;Laplacian Green 公式和边界条件 $|\nabla u|^{p-1}=k^{p-1}$，再用非负曲率下的周长比较得到严格不等式。充分性中，积分条件排除最优域与 C 接触，因而第一阶系统在整个自由边界给出等梯度条件；最优域即为所需解。

**原始英文摘要**

We generalize the necessary and sufficient condition of existence for the quadrature surfaces free boundary problem to the case of the $p$&#45;Laplacian operator in Riemannian geometry. Following the shape optimization approach of Barkatou for the Euclidean case and the Riemannian framework recently developed by Djité and Seck, we formulate the $p$&#45;Laplacian quadrature surface problem as a shape optimization problem on a compact Riemannian manifold. Using the Riemannian $RC$&#45;GNP condition, the stability results, and the $p$&#45;Laplacian shape derivative formula from &#92;cite&#123;DjiteSeck2026b&#125;, we prove that the $p$&#45;Laplacian quadrature surface problem $QS_p(f,k)$ admits a solution strictly containing the totally convex hull $C$ of the support of $f$ if and only if 

$$\int_C f(x)\,dv(g) > k^{p-1} |\partial C|_g,$$

 for $1 < p < \infty$, under suitable regularity and stability assumptions. This extends the Euclidean result of Barkatou for $p=2$ and the Riemannian result of Djité and Seck to the nonlinear $p$&#45;Laplacian setting. Explicit examples on the round sphere are provided, including the computation of the radial $p$&#45;harmonic solution and the boundary flux.
