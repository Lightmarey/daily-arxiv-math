**完成的工作**

**可能的突破**

在螺旋对称下把三维涡量的关键非线性压缩到可控的二维结构，允许仅 L1 初始涡量并获得全局强解。

**限制与不确定性**

螺旋对称$、R2\\times T$ 几何和无散约束不可去除；全局性依赖初值 L1 与文中对称结构，不覆盖一般三维 Navier--Stokes。

**证明逻辑/大纲**

1. **主张：** 螺旋对称场的速度和涡量可由标量分量表示。
   - **路线：** 在柱坐标/螺旋坐标中展开不变性条件，将 divergence-free 约束转成流函数关系；Biot--Savart 表示给出速度由涡量的积分控制。
2. **主张：** 线性热-输运方程给出 L1 到 Lp 的短时平滑估计。
   - **路线：** 对约化涡量方程使用热半群和 Duhamel 公式，利用 Riesz 变换有界性控制非局部速度项，得到 $t-\\alpha $ 的 Lp 界。
3. **主张：** 固定点方法构造唯一局部 mild 解并给出连续依赖。
   - **路线：** 在时间加权 Lp 空间中定义双线性演化映射，Proposition 2\.12 控制二次项；差值估计使映射收缩，得到 Theorem 3\.2 和 Corollary 3\.4。
4. **主张：** 涡量 L1 控制排除有限时间爆破并延拓解。
   - **路线：** 利用涡量符号/螺旋结构和局部能量估计获得时间一致的 L1 界；在任意有限时刻重启局部构造，Theorem 3\.5 的 continuation criterion 给出全局解和唯一性。

**原始英文摘要**

We show that the Navier-Stokes equations on $\\mathbb R^2\\times\\mathbb T$ are globally well posed for initial vorticities that are both helically symmetric and integrable\. This class of data typically generates velocity fields of infinite kinetic energy, so this result is not covered by the classical finite-energy well-posedness theory\. This result is supercritical from the perspective of the three-dimensional Navier-Stokes scaling, and it is made possible by the special structure of helical flows using time-weighted Kato-type spaces\.
