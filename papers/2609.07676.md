**完成的工作**

这份讲义整理奇异 SPDE 中从多重指标到装饰树的 chain rule symmetry。作者先用正规性结构和 B&#45;series 展开编码广义 KPZ 的重整化项，再用积分分部和 elementary differentials 建立多重指标的链式法则；随后定义由微分同胚作用不变的几何子空间，证明它是组合映射 $phi_hat_geo$ 的核。最后以组合协变导数生成该核，并通过带微分的 operad 同调把它识别为 Lie&#45;admissible operad，从而解释几何 KPZ 反项的局部性。

**使用技术**

- 正规性结构与 B&#45;series 展开
- 装饰树和多重指标编码
- elementary differential 单射
- 协变导数与 Lie bracket
- operad 同调与 Lie&#45;admissible 结构

**可能的突破**

讲义把解析的链式法则对称性压缩成可计算的核条件 $phi_hat_geo=0$，并证明该核恰由迭代协变导数生成、同调上等同于 LieAdm；这给出从重整化反项到几何不变量的统一组合判据。

**限制与不确定性**

本文是结果综述与讲义，若干正规性结构背景定理和 Proposition 4.7 的完整维数证明引用前作；结论集中于广义 KPZ、几何 KPZ 的特定装饰树/多指标系统，不直接覆盖任意奇异 SPDE 或任意噪声维数。

**证明逻辑/大纲**

1. **主张：** 多重指标和装饰树的 elementary differential 能区分所需的重整化组合，从而可表达链式法则。
   - **路线：** 先以树或多重指标递归编码积分核、噪声和导数，再把每个组合映射到 f、g 及其导数构成的 elementary differential；Theorem 2.4 的单射性使组合恒等式可由对所有测试函数的解析恒等式反推。
2. **主张：** 重整化方程的 chain rule symmetry 恰等于组合空间中 $phi_hat_geo$ 的核。
   - **路线：** 对任意同伦于恒等的微分同胚族求一阶变分，函数复合贡献 Lie bracket，二阶链式项贡献 $phi_geo$；将两者相减得到 $phi_hat_geo$，并利用 elementary differential 的单射性把解析不变性等价化为核条件。
3. **主张：** 协变导数保持几何对称空间，迭代协变导数生成的集合包含在 $V_geo$。
   - **路线：** 定义组合协变导数为 v1 Dv2 加上 $z_(f,0)$ v1 v2 的修正项，使其在 elementary differential 下正好对应解析协变导数；对 $phi_hat_geo$ 使用 Leibniz 规则和 bracket 恒等式，证明闭包命题 Proposition 4.5。
4. **主张：** N 阶几何对称空间由迭代协变导数生成，且其维数等于相应多重指标空间。
   - **路线：** 先用投影 pi 把带导数变量消去，借助树的 grafting 递归说明协变导数张成全部无厚边树；再对 $phi_hat_geo$ 的方程建立按变量数的三角系统，分别给出上下维数界，得到 Propositions 4.6&#45;4.7 和 Theorem 4.8。

**原始英文摘要**

In these lecture notes, we review the recent results around the chain rule for the generalised KPZ equation and the geometric KPZ equation. We introduce the main ideas of Regularity Structures via a B&#45;series type expansion and the two main combinatorial sets for encoding this expansion: decorated trees and multi&#45;indices. Then, we explain how the chain rule was first understood via integration by parts and diagrammatic computations. For the generalised KPZ equation, a scalar&#45;valued equation, we use multi&#45;indices to derive a characterisation in terms of iterations of covariant derivatives. The same characterisation for decorated trees is more involved and requires the use of operadic and homological tools. We summarise the main arguments of this proof.
